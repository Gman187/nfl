graphs on Power BI or Tableau. What those applications did not do is teach the inner workings of the Why. Why calling a series for the code mattered, Why methods within a class are abstractions, and Why did all of these work together to

Building an initial framework, I set out to build a class to create a DataFrame to allow various Data Analysis to be performed on. Currently in this version 
.0.0.1 is just a framework. I plan on adding more graphs, changing the colors around, adding more depth to the dashboard to allow cross analysis with other teams.
